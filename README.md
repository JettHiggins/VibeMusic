# VoiceSynthesizer

A voice-controlled browser groovebox built around SLOOP.

Read [PLAN.md](PLAN.md) and [AGENTS.md](AGENTS.md), then follow [setup](docs/SETUP.md) and [contracts](docs/CONTRACTS.md).

Milestone 0 provides shared contracts, JSON Schemas, fixtures, mock adapters, a mock browser shell, and a pinned upstream engine source. Real SLOOP browser playback and clock-scheduled commands are now implemented. Microphone analysis, the full editing UI, and sound research remain pending integration. A local transcript-command service is integrated; speech recognition and Deep Agents remain pending. API access is deferred.
