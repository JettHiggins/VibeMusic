# VoiceSynthesizer

A voice-controlled browser groovebox built around SLOOP's actual WASM engine. Create drum loops, sing melodies into a live piano roll and use speech to control the session or request sounds.

**Use engine-integration for the runnable app.** Main is still the older documentation baseline. Real playback, microphone capture, live editing, local speech and optional OpenRouter Deep Agents are integrated. Reliable physical melody capture and full hands-free sound design remain unfinished; Google Cloud/Vertex migration is planned.
