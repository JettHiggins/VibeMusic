# Backend OpenRouter / Deep Agents handoff

Optional backend-only configuration and a real Deep Agents graph now support contract-derived musical command tools plus typed sound search/refine/accept/cancel. Familiar commands retain the parser path; unknown addressed speech uses a bounded asynchronous worker. The user has configured the backend key locally. Initial live smoke tests are recorded below; the configurable free candidate is unranked.

Boundaries: official API base, zero price caps, no paid models/fallback/retry; three model/four tool calls and timeout; one running/four queued requests per socket. Filesystem/delegation tools cannot execute. Tools return proposals, independently validated before browser validation. Exactly one action per run; no partial application. Raw audio, notes and patch payloads are not sent to the model. Known research candidates supply accepted patches. No automatic audition operation is invented.

Wake exclusion precedes classified coverage without waiting on the provider. Late results cannot mutate ended/new takes, new clocks/revisions, newer edits including discard-only Undo, or replacement candidate lists. Disconnect cancels inference. Provider exceptions become fixed timeout/quota/auth/general errors; raw exception/credential text is never forwarded.

PR validation distinguishes scripted graph tests from provider quality. Tests cover actual WebSocket concurrency (Clear succeeds during delayed inference, then its obsolete result is refused), queue/deduplication/take/clock/revision guards, schema validation and bounded model execution. Shared Node/schema/live-service/WASM/build checks passed. Setup is in README.md and .env.example; language_check.py performs explicitly opted-in individual measurements.

Fresh dev+LLM installation: 209 passed, 6 optional skips, pip check clean. All 38 language tests passed. Actual SDK mock-HTTP tests verify the single-call tool round trip, one request on 429/500, millisecond timeouts, transmitted zero price caps and no sensitive debug logs. SDK 0.11.46 needs price strings: numeric zero silently dropped the entire provider object. The SDK client explicitly uses retry_config=None because ChatOpenRouter max_retries=0 otherwise leaves the SDK default active. No provider network request is made by those tests. Node suite: 150 passed/one optional skip; explicit live service/WASM test and production build passed.

First run timed out at 8 s with no mutation; a later run with a 30 s diagnostic budget succeeded in 6.8 s. Proposal tools now return directly, avoiding a second model call; another live run succeeded in 7.6 s. This reduces request count, not a demonstrated latency improvement: free-provider latency varied and no p95/corpus accuracy is established. The routine test suite disables environment-enabled model providers before app import, so a developer's configured .env cannot accidentally enable network inference in ordinary tests. A known irrelevant optional-video probe warning is suppressed for this audio-only tool harness.

These CLI probes validate proposals/refusal, not actual research execution, browser playback or a corpus win rate. The sound request's latency exceeds the default 8 s budget, so free-model responsiveness remains an open measured limitation.
