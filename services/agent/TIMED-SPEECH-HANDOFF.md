# Joined singing / Stop exclusion

WS1's bdb4ffc browser test reproduces a half-second pause joining C4/E4/G4 singing and Groove stop in one energy segment. This capability leaves segmentation and the two-second held-wake join intact. The local faster-whisper adapter now supplies word alignment internally. The connection uses the recognized wake onset with 120 ms pre-roll to exclude command speech, preserving earlier melody. Frame conversion uses the original segment capture/payload ratio, not the resampled 16 kHz rate. Capture context uses the actual word onset rather than the singing onset or padded exclusion start. Only sung syllable prefixes can be removed; ordinary conversation keeps its existing wake gate.

Exclusion retains the measured segment end plus up to 120 ms of already-classified quiet for weak final consonants. It cannot extend through an open segment or beyond classified audio. Missing/invalid alignment remains conservative whole-segment exclusion. No wire schema changes. Providers returning plain strings retain their existing behavior. Delayed/held results still use capture-time context and exclusion precedes proposals and coverage.

Word alignment can make faster-whisper rewind its seek to the last word and decode a phantom tail (observed extra Stop/Bye/up on synthetic speech). For clips within one 30-second window, the adapter retains without_timestamps=True and takes the first full-window decode including all its words; streaming clips are at most four seconds. It does not re-decode the aligned tail. No parser relaxation or hangover reduction is used.

Validation: deterministic 16/44.1 kHz pipeline cases preserve preceding music, test timed held wakes and capture-window changes; alignment tests cover invalid/missing/out-of-order/NaN timestamps and conversation prefixes. The opt-in real-model test in test_stt.py now includes three harmonic tones, exactly 0.5 s silence, and trimmed synthetic Groove stop through the actual segmenter, threaded recognizer, Connection and schema validation. With Microsoft Zira Desktop synthetic speech, base.en CPU/int8 decoded one joined segment and emitted Stop recording with exclusion [433943,472749] on a 44.1 kHz clock starting at 352800. The last note ends at 418950, so all notes precede exclusion. The original real-model opt-in test passed too (~0.49 s from streaming to command on this run). This is a backend/synthetic result, not physical voice quality or browser/YIN acceptance. No raw human recording is used or committed.
